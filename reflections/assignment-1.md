# Assignment 1 Reflection

## What was the breakthrough that moved the work forward?

The main breakthrough was realising that a technically working interaction was not enough. My first versions let the user choose distance, running days and intensity, but the page started to feel like a running-plan generator. That was not the idea I wanted to explain.

Instead of adding more features, I kept the same basic interaction and changed how it was presented. The controls became variables to experiment with, and the result showed how simple choices already create decisions about weekly distance, frequency, effort and recovery. After this change, the page felt much closer to an interactive explainer rather than a tool telling the user how to train.

## What did this work change about who I want to be as a software developer?

This assignment made me want to be more deliberate about scope and design decisions. Using an agent can make implementation fast, but it can also produce a lot of work in the wrong direction if the goal is not clear.

I found it more useful to narrow the idea first, build a small prototype, research claims before using them, and then judge the actual result rather than accepting it because the code worked. I want to use AI as an implementation and iteration tool, while still making the important decisions about purpose, evidence and whether the final result actually communicates the idea.
